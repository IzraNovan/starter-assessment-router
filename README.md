## 📌 Fitur Utama

- **Home:**
  Halaman utama yang menyambut pengguna dengan selamat datang dan tampilan yang informatif.

- **Santri (Dynamic Sidebar):**
  - **Sidebar Persisten:** Sidebar tetap muncul dan tidak ter-render ulang saat berpindah menu.
    - **Menu Sidebar:**
      - **List:** Menampilkan daftar santri dalam bentuk _SantriCard_ (3 data saja). Klik pada _SantriCard_ untuk navigasi ke halaman `SantriDetail` (Sidebar tetap tampil).
      - **Nilai:** Halaman yang menampilkan tulisan "Daftar Nilai Santri".
      - **Absensi:** Halaman yang menampilkan tulisan "Absensi Santri".

- **Santri Detail:** Tampilkan id dari santri yang di pilih menggunakan hooks `useParams`

- **About:**
  Halaman informasi tentang website beserta kontak sederhana.

- **Not Found:**
  Penanganan untuk route yang tidak terdaftar (404 Page).
